# JieDian (节点)

[一起来做主节点，一起来挖矿](https://jiediantech.github.io/jiedian/) — 一站式家用分布式算力与节点平台。

## 关于我们

**上海筱兰信息科技（Btcat）** 是一家专注于区块链设备设计与研发的科技公司。核心团队成员来自腾讯、OPPO、华为、航天华拓等国内科技独角兽，在智能硬件、Linux 系统、服务器开发等方面拥有深厚的软硬件研发经验。

2018 年，筱兰科技获得 [布洛克资本](https://www.blockvc.com/) 战略投资。

## 业务板块

| 产品 | 说明 |
|------|------|
| **POW 矿场** | 显卡矿机托管，业内领先的软硬件挖矿技术，每月分红 |
| **POS 节点盒子** | 家用硬件节点，支持 Ulord、IPFS、FIBOS 等公链，一键部署，坐享节点收益 |
| **云服务器** | 高配云服务器，适用于个人网站及中小型企业站点 |

## 核心优势

- 回本周期行业领先
- 每台设备自带独立公网 IP
- 分布式节点网络，抗单点故障
- 最低 50M 带宽即可参与
- 收益不仅限于单一币种

## 目标

建设更丰富、更有趣、更靠谱的区块链基础设施生态，为全球上千条公链网络提供基础层支持与保障。
